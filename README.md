# Lij
A 70-card deck of nature emblems and six games to play with it. See CLAUDE.md for the design notes and build commands.
- `dist/Lij-deck-print.pdf` – print at 100% on card stock.
- `dist/Lij-deck-print-emblems.pdf` – the same deck with emblem badges in place of scenes.
- `dist/Lij-games.html` – open in any browser to play.
